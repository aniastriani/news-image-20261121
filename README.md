The World in One Image — Saturday 21 November 2026. A newspaper front
page that sums up the day's world news in one picture: Russian missiles
crash in Poland during a massive barrage on Ukraine, COP31 talks stall
in overtime, Ukraine peace talks edge forward, Myanmar rejects the
world court's genocide ruling, the UK and EU strike a landmark deal,
and a tanker is struck in the Strait of Hormuz.

`main.py` draws the whole page with the Python standard library only —
a hand-drawn 5x7 pixel font, small vector illustrations, and a PNG
writer built by hand. No network, no clock, no randomness: every run
writes the same bytes.

## Run it

```sh
python3 main.py
```

The picture is written to `/output/entry.png`, or to
`$MAKEFUN_OUTPUT_DIR` when that variable is set.
